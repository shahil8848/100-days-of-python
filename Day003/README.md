# 🐍 Day 3 - Python Beginner Projects & Conditionals

Today, I learned about:

✅ Python conditional statements (`if`, `elif`, `else`)  
✅ Nested conditionals for decision making  
✅ Logical operators (`and`, `or`, `not`)  
✅ Handling user input with `.lower()` for case-insensitive comparisons  
✅ Creating interactive console-based games and apps

---

### 🧾 Projects Built:

#### 1. 🍕 Python Pizza Delivery
Simulates a pizza ordering system based on size and extras like pepperoni and cheese. Calculates and displays the final bill.

#### 2. 🏴‍☠️ Treasure Island Adventure Game
A text-based adventure game with multiple decision points that lead the user to different endings (like treasure, dragon, or goblins!).

#### 3. 🎢 Rollercoaster Ticketing System
Checks if a user is tall enough to ride a rollercoaster, then calculates the ticket price based on age. Adds photo charges if needed.

---

### 💡 Key Learnings

- How to nest `if` statements for multi-level decisions
- Using `input().lower()` to standardize user input
- Updating a variable like `bill` as the program progresses
- Writing readable, well-structured CLI applications
