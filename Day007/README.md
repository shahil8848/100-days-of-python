# Hangman Game 🎮
A simple Hangman game built in Python as part of my #100DaysOfCode challenge!

## Features
- Random word selection from a word list
- Life system with visual stages (ASCII art)
- Tracks all guessed letters
- Shows wrong guesses separately
- Game ends with win/lose messages

## How to Play
- Guess letters one by one.
- Each wrong guess reduces a life.
- Already guessed letters will either warn you (or cost a life based on the version you run).
- Win if you guess the whole word before running out of lives!

## Files
- `main.py` — Main game logic
- `hangman_art.py` — Hangman logo and stages (ASCII art)
- `hangman_words.py` — List of words for random selection

## Concepts I Practiced
- Working with lists and loops
- Using functions like `random.choice()`
- String manipulation
- If/else control flows
- Game logic building
- Modular code splitting across multiple files
