Day 4: Python - Lists, Randomisation, and Rock Paper Scissors

🧠 What I Learned

✅ Lists

Created and accessed elements in a list.

Indexed lists using numbers.

Nested lists (a list within a list).

Used methods like append(), extend(), insert(), remove(), and pop().

✅ Random Module

Imported and used Python's random module.

random.randint(a, b) to generate random integers.

random.random() and random.uniform(a, b) for floats.

Used random.choice() to select random elements from a list.

✅ Tuples

Brief introduction to tuples (immutable lists).

🧪 Mini Projects & Experiments

1. Random State Generator

Selected random states from a list of US states using indexing and random.randint().

2. Dirty Dozen Nested List

Organized fruits and vegetables into nested lists and accessed specific items via list[index][index].

3. Coin Toss Simulator

Used random.randint(1, 2) to simulate a coin toss (Heads or Tails).

4. Rock, Paper, Scissors Game

Implemented the classic game using conditionals and list indexing.

Added ASCII art for fun visual feedback.

Compared user and computer choices to determine the winner.
