100 Days of Python: A Code-tastic Adventure 🐍

Welcome to my 100 Days of Python journey, where I wrestle with code, conquer bugs,
and occasionally talk to my rubber duck for moral support. 
This repository is my digital diary of learning Python from "Hello, World!" to (hopefully) building AI 
that doesn’t take over the world... yet.

What’s This All About? 🤔

For 100 days, I’m diving headfirst into Python with daily exercises, 
projects, and the occasional facepalm when I forget a colon 
(yep, SyntaxError is my old friend). From variables to machine learning,
I’m leveling up one commit at a time. Think of this as a sitcom: part comedy, 
part drama, all coding.


Goals 🎯

Master Python fundamentals without crying over indentation errors.
Build cool projects (think games, web scrapers, or a bot that orders pizza).
Laugh at my own mistakes and share the lessons with the world.
Survive 100 days without switching to JavaScript in a moment of weakness.
